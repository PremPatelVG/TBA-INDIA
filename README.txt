TBA India static HTML website

Open index.html in a browser to preview the website.

Pages:
- index.html
- about-us.html
- contact-us.html
- our-leadership-team.html
- terms-and-conditions.html
- privacy-policy.html
- ada.html

Assets:
- assets/images contains the logo and leadership images.
- assets/css/styles.css contains local brand styling.
- assets/js/main.js controls the mobile menu, 5-second auto-close, contact form popup, and form submission.

Tailwind:
The HTML pages use Tailwind CSS responsive utility classes through the Tailwind CDN. Keep the internet available when previewing locally, or replace the CDN with a compiled Tailwind CSS file before offline hosting.
